The program performs the following steps:
1.  **Reads and trims the trial ID** from `/logs/artifacts/trial_id`.
2.  **Computes and normalizes bucket names**: It derives `sourceBucket` and `forkPrefix` by converting the trial ID to lowercase and replacing underscores with hyphens, as per S3 naming conventions and the task requirements.
3.  **Creates forks**: It uses `@tigrisdata/agent-kit`'s `createForks` to provision 3 copy-on-write fork buckets from the source bucket.
4.  **Parallel writes**: It uses `Promise.all` to concurrently write a distinct `worker/output.txt` object (containing `worker-0`, `worker-1`, `worker-2`) into each of the three fork buckets using `@tigrisdata/storage`'s `put` method.
5.  **Audit output**: It prints the resulting fork bucket names to stdout.

The code is structured as follows:
```typescript
import { readFile } from "node:fs/promises";
import { createForks } from "@tigrisdata/agent-kit";
import { put } from "@tigrisdata/storage";

async function main() {
  try {
    const rawTrialId = await readFile("/logs/artifacts/trial_id", "utf-8");
    const trialId = rawTrialId.trim();

    const normalizedTrialId = trialId.toLowerCase().replace(/_/g, "-");
    const sourceBucket = `harbor-source-${normalizedTrialId}`;
    const forkPrefix = `harbor-fork-${normalizedTrialId}`;

    const forkResponse = await createForks(sourceBucket, 3, { prefix: forkPrefix });

    if (forkResponse.error) {
      console.error("Error creating forks:", forkResponse.error);
      process.exit(1);
    }

    const forkSet = forkResponse.data;
    const writePromises = forkSet.forks.map((fork, i) => {
      return put("worker/output.txt", `worker-${i}`, { config: { bucket: fork.bucket } });
    });

    await Promise.all(writePromises);

    forkSet.forks.forEach((fork) => {
      console.log(fork.bucket);
    });

  } catch (error) {
    console.error("Program failed:", error);
    process.exit(1);
  }
}

main();
```
