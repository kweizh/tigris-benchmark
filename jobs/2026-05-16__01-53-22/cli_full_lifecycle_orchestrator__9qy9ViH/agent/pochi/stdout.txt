This task asks you to chain those primitives together into a single bash script — exactly the kind of recipe that operators use to bootstrap, exercise, and clean up ephemeral storage for an agent run. Snapshots MUST be enabled at bucket-creation time (the `--enable-snapshots` flag); they cannot be added to an existing bucket. The flow below is sequential — each step depends on the previous one — and the script must clean up after itself by deleting the bucket at the end. ## Requirements Write a single bash script at `/home/user/lifecycle/run.sh` that, **using ONLY the Tigris CLI (`tigris`)**, performs the following steps in order: 1.
