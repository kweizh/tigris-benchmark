Validates that both the bucket and scoped credentials are present in the response (throw a descriptive error otherwise). 3. Uses the AWS SDK for JavaScript v3 (`@aws-sdk/client-s3`) — configured with ONLY the scoped credentials from the workspace (NOT the admin `TIGRIS_STORAGE_ACCESS_KEY_ID`/`TIGRIS_STORAGE_SECRET_ACCESS_KEY` env vars) and the Tigris endpoint (`REDACTED`, region `REDACTED`) — to `PutObject` a file with key `greeting.txt` and body `hello scoped` into the workspace bucket. 4.
