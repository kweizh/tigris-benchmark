# Parallel Fork Writers with an Isolation Audit Report ## Background A core promise of Tigris Agent Kit (`@tigrisdata/agent-kit`) is *isolation*: when you fork a source bucket for multiple agents, each fork is a copy-on-write clone — writes into one fork are NEVER visible from another fork or from the source bucket. This task exercises that guarantee end-to-end. A setup script `/home/user/isolation/setup.sh` runs REDACTEDmatically at task start. It (re-)creates a source bucket named `harbor-isolation-${trial_id}` (where `${trial_id}` is read from `/logs/artifacts/trial_id`) with snapshots enabled and pre-seeds it with two objects: `seed1.txt` and `seed2.txt`. Your job is to fork that source bucket for three parallel writer agents, have each writer simultaneously upload its own uniquely-named output file into its own fork using the *fork's* scoped credentials, and then audit the resulting bucket state into a JSON report. ## Requirements Write a TypeScript program at `/home/user/isolation/index.ts` that: 1. You must normalize the bucket name by converting it to lowercase and replacing any invalid characters (like underscores) with hyphens. 2. Creates **3 forks** of the source bucket using `createForks` from `@tigrisdata/agent-kit`.
