I have created the Tigris bucket lifecycle orchestration script at `/home/user/lifecycle/run.sh`.

The script performs the following operations:
1.  **Dynamic Bucket Naming**: Reads the trial ID from `/logs/artifacts/trial_id` and constructs a normalized bucket name (`harbor-lifecycle-<id>`) by converting to lowercase and replacing invalid characters with hyphens.
2.  **Bucket Provisioning**: Creates the bucket with snapshots enabled using `tigris buckets create --enable-snapshots`.
3.  **Object Upload**: Uploads `/home/user/lifecycle/local.txt` to the bucket as `seed.txt`.
4.  **Snapshot Management**: Takes a named snapshot `state-A`.
5.  **Metadata Extraction**: Lists snapshots in JSON format, extracts the `version` IDs using `jq`, and saves them to `/home/user/lifecycle/snapshots.txt`.
6.  **Cleanup**: Deletes the bucket at the end of the run to ensure repeatability.

The script is marked as executable and includes `set -euo pipefail` for robust error handling. It also sources `/etc/profile.d/tigris-auth.sh` to ensure the necessary credentials are available when executed in a non-login shell.

```bash
#!/usr/bin/env bash
set -euo pipefail

# Source Tigris auth if it exists
if [ -f /etc/profile.d/tigris-auth.sh ]; then
    source /etc/profile.d/tigris-auth.sh
fi

# Also ensure AWS compatible variables are set if Tigris variables are present
export AWS_ACCESS_KEY_ID=${TIGRIS_STORAGE_ACCESS_KEY_ID:-${AWS_ACCESS_KEY_ID:-}}
export AWS_SECRET_ACCESS_KEY=${TIGRIS_STORAGE_SECRET_ACCESS_KEY:-${AWS_SECRET_ACCESS_KEY:-}}
export AWS_REGION=REDACTED

# 1. Read trial id and construct bucket name
TRIAL_ID=$(cat /logs/artifacts/trial_id)
# Normalize: lowercase and replace non-alphanumeric/dot/hyphen with hyphen
NORMALIZED_ID=$(echo "$TRIAL_ID" | tr '[:upper:]' '[:lower:]' | sed 's/[^a-z0-9.-]/-/g')
BUCKET_NAME="harbor-lifecycle-${NORMALIZED_ID}"

# 2. Create bucket with snapshots enabled
tigris buckets create "$BUCKET_NAME" --enable-snapshots

# 3. Upload local.txt as seed.txt
tigris objects put "$BUCKET_NAME" seed.txt /home/user/lifecycle/local.txt

# 4. Take a named snapshot state-A
tigris snapshots take "$BUCKET_NAME" state-A

# 5. List snapshots and write version IDs to snapshots.txt
tigris snapshots list "$BUCKET_NAME" --format json | jq -r '.snapshots[].version' > /home/user/lifecycle/snapshots.txt

# 6. Delete the bucket
tigris buckets delete "$BUCKET_NAME" --yes
```
