# Prefix-Collision-Safe Forking with Tigris Agent Kit ## Background `createForks` from `@tigrisdata/agent-kit` creates N copy-on-write fork buckets from a source bucket. When you pass `prefix`, fork bucket names are `${prefix}-0`, `${prefix}-1`, etc. However, if any bucket with that prefix already exists from a previous (failed or aborted) run, `createForks` can stop early or return fewer forks than requested due to naming collisions. Production agent runners therefore need a *safe* fork helper that detects and cleans up prefix collisions before forking. The Tigris environment for this task starts with: - A snapshot-enabled source bucket named `source-bucket`. - A leftover bucket named `eval-prefix-stale-001` (simulating a previous aborted fork run that used the same prefix). Your job is to implement a safe forker that defensively cleans up any pre-existing `eval-prefix*` buckets before forking, then runs `createForks` and tears the new forks down at the end. ## Requirements Write a TypeScript script at `/home/user/safe-fork/index.ts` that performs the following in order: 1. **Detect prefix collisions.** Enumerate all existing buckets in the Tigris account and identify every bucket whose name starts with `eval-prefix`. Use either the Tigris CLI (`tigris buckets list`) via `child_process` or the `@tigrisdata/storage` SDK (`listBuckets`). At least one such bucket (`eval-prefix-stale-001`) is expected at start. 2. **Delete colliding buckets.** Delete every bucket discovered in step 1 BEFORE calling `createForks`. You may use `removeBucket` from `@tigrisdata/storage`, the AWS S3 SDK, or `tigris buckets delete <name> --force`. The bucket `source-bucket` MUST be left untouched. 3. **Create forks.** Call: ```ts import { createForks } from "@tigrisdata/agent-kit"; const { data: forkSet, error } = await createForks("source-bucket", 3, { prefix: "eval-prefix", credentials: { role: "Editor" } }); ``` Verify that `error` is undefined and that exactly 3 forks were created. 4. **Record fork names.** Write the 3 fork bucket names to `/home/user/safe-fork/forks.json` as valid JSON in the exact shape: ```json {"forks": ["eval-prefix-0", "eval-prefix-1", "eval-prefix-2"]} ``` The names MUST be read from `forkSet.forks[i].bucket` (do not hardcode them). 5. **Tear down the new forks.** After writing `forks.json`, call `teardownForks(forkSet)` to delete the 3 fork buckets and revoke their scoped access keys. The source bucket `source-bucket` MUST remain in place. The script must exit with status 0 on success. Credentials are pre-provisioned via `TIGRIS_STORAGE_ACCESS_KEY_ID` and `TIGRIS_STORAGE_SECRET_ACCESS_KEY` environment variables. ## Implementation Guide 1. The project at `/home/user/safe-fork` is already scaffolded with `package.json` declaring `@tigrisdata/agent-kit`, `@tigrisdata/storage`, `tsx`, and `typescript`. Run `npm install` once before authoring the script. 2. Run the script with `npx tsx index.ts` from inside `/home/user/safe-fork`. 3. Agent Kit calls return `TigrisResponse<T>` discriminated unions — always check `result.error` before reading `result.data`. 4. The Tigris S3 endpoint is `https://t3.storage.dev`. ## Constraints - Project path: `/home/user/safe-fork` - Source bucket name: `source-bucket` (already exists with snapshots enabled; must NOT be deleted) - Fork prefix: `eval-prefix` - Fork count: `3` - Output file: `/home/user/safe-fork/forks.json` with shape `{"forks": [<3 unique names>]}` - Every name in `forks` MUST start with the string `eval-prefix`. - The pre-existing bucket `eval-prefix-stale-001` MUST be deleted by your script BEFORE forking. - The 3 new fork buckets MUST be torn down by your script before it exits. ## Integrations - Tigris (cloud object storage). Credentials are pre-provisioned via `TIGRIS_STORAGE_ACCESS_KEY_ID` and `TIGRIS_STORAGE_SECRET_ACCESS_KEY`.
