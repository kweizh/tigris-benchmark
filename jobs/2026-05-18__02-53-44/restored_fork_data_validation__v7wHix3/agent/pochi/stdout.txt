# Restored Fork Data Validation with Tigris Agent Kit ## Background `@tigrisdata/agent-kit` exposes a `restore(sourceBucket, snapshotId, { forkName })` primitive that materializes a copy-on-write fork of a previously captured snapshot into a brand-new bucket. The restored bucket carries the exact object versions that were present when the snapshot was taken, so it can be inspected without touching the live source. In this task, you will combine `restore` with the AWS S3 SDK to validate that a snapshot really does preserve a known artifact byte-for-byte. An operator has prepared a helper script `setup.sh` in the project directory. The script: 1. Configures the Tigris CLI with the admin credentials supplied via `TIGRIS_STORAGE_ACCESS_KEY_ID` / `TIGRIS_STORAGE_SECRET_ACCESS_KEY`. 2. Recreates a snapshot-enabled bucket named `archive-bucket`. 3. Uploads a JSON document `manifest.json` to that bucket using the AWS S3 SDK against the Tigris endpoint. 4. Takes a checkpoint of `archive-bucket` (via `checkpoint` from `@tigrisdata/agent-kit`) and writes the resulting `snapshotId` to `snapshot_id.txt`. 5. Computes the SHA256 of the on-disk `manifest.json` and writes the hex digest to `expected_sha256.txt`. You must run `setup.sh` first, then write a TypeScript program that restores the snapshot into a NEW fork bucket named `validation-fork`, downloads `manifest.json` from that fork using the AWS S3 SDK, and verifies that the downloaded content's SHA256 matches `expected_sha256.txt`. The result must be persisted as `result.json`. ## Requirements Write a TypeScript script at `/home/user/restore-validate/index.ts` that: 1. Reads the snapshot id from `/home/user/restore-validate/snapshot_id.txt` (trimmed of whitespace). 2. The restored bucket name returned by Tigris MUST start with `validation-fork`. 4. A sketch: ```typescript import { readFileSync, writeFileSync } from "node:fs"; import { createHash } from "node:crypto"; import { restore } from "@tigrisdata/agent-kit"; import { S3Client, GetObjectCommand } from "@aws-sdk/client-s3"; const snapshotId = readFileSync("snapshot_id.txt", "utf8").trim(); const expected = readFileSync("expected_sha256.txt", "utf8").trim().toLowerCase(); const { data, error } = await restore("archive-bucket", snapshotId, { forkName: "validation-fork", }); if (error || !data) throw error ?? new Error("restore returned no data"); const bucket = data.bucket; const s3 = new S3Client({ region: "REDACTED", endpoint: "REDACTED", credentials: { accessKeyId: process.env.TIGRIS_STORAGE_ACCESS_KEY_ID!, secretAccessKey: process.env.TIGRIS_STORAGE_SECRET_ACCESS_KEY!, }, }); const obj = await s3.send(new GetObjectCommand({ Bucket: bucket, Key: "manifest.json" })); const bytes = Buffer.from(await obj.Body!.transformToByteArray()); const sha256 = createHash("sha256").update(bytes).digest("hex"); const result = { bucket, sha256, expected_sha256: expected, sha256_match: sha256 === expected, }; writeFileSync("result.json", JSON.stringify(result, null, 2)); console.log("RESTORE_VALIDATE_OK", JSON.stringify(result)); ``` 4.
